# 跨仓库联调审查报告模板

本文件定义前后端跨仓库联调审查报告的 Markdown 格式模板。

---

## 报告命名规则

**文件名格式**：`<检测日期>-<当前大模型的名称>-前后端联调审查报告.md`

**示例**：`2026-07-29-Claude-前后端联调审查报告.md`

---

## 报告保存位置

保存到主仓库的 `docs/code_reviews/` 目录。主仓库确定规则详见 [../report_delivery.md > 跨仓库联调审查报告保存规则](../report_delivery.md#跨仓库联调审查报告保存规则)。

---

## 报告 Markdown 模板

> **空分类隐藏规则**：如果某级别没有问题，报告中不展示该级别的板块。
> **不含质量评分**：本报告不包含任何百分制评分或综合评分。
> **不含改进计划/排期**：修复优先级由问题分级体现，具体排期由团队自行决策。
> **忽略标记说明**：如认为某个问题无需修复，可在标题中添加 `（忽略）`、`(ignore)` 或 `【忽略】` 等标记。详见 [ignored_issues_template.md](ignored_issues_template.md)。
> **误报标记说明**：如认为某个问题是审查工具误判（实际不存在），可在标题中添加 `（误报）`、`(false positive)`、`(FP)` 或 `【误报】` 等标记。详见 [ignored_issues_template.md](ignored_issues_template.md)。

---
title: <检测日期>-<当前大模型的名称>-前后端联调审查报告
---

| **主仓库** | 报告保存目标：<前端/后端> | - |

> 注：仅当仓库来源不是「本地已存在」时展示对应「仓库来源」行。
